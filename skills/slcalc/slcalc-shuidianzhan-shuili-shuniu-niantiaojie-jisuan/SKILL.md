### 算法要点（已对权威 C-14.OUT 反演裁定）

| 项目 | 公式 / 规则 |
|---|---|
| 水量平衡 | `V = VB + (QJ − QO − QB − QW) / TIMEM3[计算期]` |
| 上游水位 | `H = f(VV→HV)(V)`；平均水位用 `0.5·(VB+V)` 查库容曲线 |
| 水头 | `DH = H(平均库容) − h(QO) − DHJANG`（下游水位流量关系插值） |
| 出力 / 电量 | `N = 8.3·QO·DH/1e4`（万kW）；`E = N·DTT/1e4`（亿kW·h） |
| 峰荷出力 | `F = f(CPN→TNH)(N)`，曲线号由 `KCPTN` 指定 |
| 方法 1 / 2 | 逐时段由 `VSTART` / `VMAX` 控制库容，反推 QO |
| 方法 3（等流量） | `QO = [Σ(QJ−QW) + (VB−V_target)·TIMEM3] / n` |
| 方法 4（等出力） | 全期恒定 N，期末库容落于 `\|V_end − V_target\| ≤ EPSV` |
| 方法 5（定出力） | 由已知出力 `CNO` 逐时段反解 QO |

### 验证结论摘要

对拍权威 `C-14.OUT`（42 行 × 12 列 + 6 项汇总行）：

- **显示精度逐位命中 42/42** 的列：时段序号、时段长、入库流量、发电流量、
  弃水流量、综合用水、出力、电量、峰荷出力（共 9 列）
- 库水位 37/42、水头 37/42、库容 26/42 —— 差异为原著内层出力迭代按
  `epsn=0.0100` 万 kW 停代（ΔQO ≈ 0.13 m³/s）在水量平衡链上的累积漂移，
  最大 `|ΔV| = 0.165`，全部落在已声明包络内
- 汇总 6 项 `|Δ| ≤ 0.02` 全中：CNCP 19.8313 / EQCP 18.5357 / CPDH 72.6125 /
  CNDH 73.2583 / EQDH 73.4442 / ΣQB 32
- `trial` 物理正向解构造性自检全通过：水量平衡 42/42、出力自洽
  `N = 8.3·QO·DH` 42/42、控制库容落位 8/8
- **唯一结构性未闭合点**：第 42 时段弃水流量。原著取 34.00，正向水量平衡解
  为 27.90；该值既不满足「压至上调度线」（需 27.90）也不满足「压至下调度线」
  （需 74.02），属原著年末收尾的独立处置，黑盒不可唯一反演，已如实标注。
- 方法 4 期末行：原著按 `epsv=3.0` 容差提前停代于 `N = 18.94`，而物理精确根
  为 `N = 19.171`；该早停点依赖原著步长/变号细节，`fit` 模式复现原著、
  `trial` 模式给物理根。

验证方式：`python c14_verify.py`（退出码 0，报告 `_c14_verify_run.txt`）；
`python c14_smoke.py`（`SLCALC_HOME=/nonexistent` 隔离，退出码 0）。
