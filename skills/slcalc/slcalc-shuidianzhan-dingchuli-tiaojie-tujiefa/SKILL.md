**验证方式**：`python c8_verify.py`（逐行解析权威 C-8.OUT → 手读 REF 交叉
核对 → trial 正向逐位对拍 → 结构不变量 → 工作曲线结构抽查 → fit 一致性
→ 显示舍入语义 → render 文本抽查 → render 主表/全文与权威 OUT 逐行比对），
退出码 0/1。

**验证结论摘要**：权威 C-8.OUT 主表 7 行 × 发电流量/时段末库容 2 列 =
14/14 逐位命中；`c8_verify.py` 汇总 **PASS=104 / FAIL=0**（退出码 0）；
`c8_smoke.py` 隔离环境 **PASS=81 / FAIL=0**；`render` 生成的计算书全文与
权威 C-8.OUT 去掉首行文件路径后**逐行逐字一致**（含标题分隔线、输入回显、
主表 7 行、尾注 DQ/VG/VH）。

**黑盒反演裁定的四个关键实现口径**：

1. **插值统一为「最近端点侧三点 Lagrange 二次插值」**（SU=3）：x 落在段
   [xs[s],xs[s+1]] 内时，若距左端点更近（或等）取三点 (s−1,s,s+1)、若距
   右端点更近取 (s,s+1,s+2)，边界退化为可用三点，界外取端点。同时用于
   (a) 工作曲线构建时"平均水位 → 平均库容"的反查（自变量 HV 升序、因变量
   VV），(b) 逐时段"FA → QO"在工作曲线上的查询。
2. **工作曲线构建**：`QO_j = NT·CC/DH_j`（DH_j = HH_j，HH=29~38）；
   平均水位 `HU_j = DH_j + 下游水位(QO_j)`；`VP_j = 库容反查(HU_j)`；
   `FA_j = VP_j + QO_j/2`。**当 HU_j 低于库容曲线最低水位（49 m）时取曲线
   首两点线性外延**（HH=29 时 HU=47.45<49 触发；若改取端点值会使该结点
   FA 抬高约 60、曲线低 FA 段畸形 → 末几行 QO 偏差 40 以上）；
   **工作曲线按 FA 升序排序后再查询**（低端外推使 FA 非单调）。
3. **逐时段**：`FA = VB + QI/2` → 工作曲线查得 QO → `V = VB + QI − QO`；
   **VB 以连续真实值逐时段滚动传递**（非显示舍入值）。裁决依据：以权威
   OUT 的整型 V 作 VB 时 QO 亦 7/7 命中，但以连续值滚动时 QO 与 V 两列
   **同时** 7/7 命中（score=14/14），连续滚动是唯一能同时命中两列的口径。
4. **显示列用 half-away-from-zero 舍入**（原著 VB 语义，非银行家舍入）；
   额定出力列按 `NT×10000` 显示整数。

**模式说明**：`compute(params, cfg)` 支持 `mode="trial"`（默认，正向图解
法，逐时段用该时段 NT 建工作曲线，不迭代）与 `mode="fit"`（核算模式，
给定 QO 序列直接滚动复现权威输出）。二者共享同一工作曲线构建/查询/显示链，
仅 QO 取值来源不同。本程序全时段无弃水（DQ=0），时段末库容自 VG=1975 起
逐时段回落至 1245（> VH=1215）。
