# A-4 水文系列代表性分析程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：孙建峰（水电部天津勘测设计院）

## 功能

㈠频率计算；㈡统计参数计算；㈢累积平均曲线；㈣差积曲线；㈤滑动平均曲线。 计算方法及公式 频率计算： 统计参数： 累积平均： 差积计算： 滑动平均：

## 算法原理

详见原程序说明书。

## 规范依据

传统计算方法，不涉及规范替代问题（见《程序集适用于新规范的说明》）。

## 输入数据（数据文件顺序）

系列长，最近年份，观测值，观测值，……,若做频率计算输入1否则输入0，若做参数计算输入1否则输入0，若做累积计算输入1否则输入0，若做差积计算输入1否则输入0，若做滑动计算输入1，滑动年数。

## 原版算例

应用某站1951年～1980年共30年降水资料进行经验频率计算、频率统计参数的计算（按m=5，6，7，…，N计算均值Cv、Cs、Cs/Cv）、累积计算、差积计算以及滑动平均计算（HT=5年）。 数据文件为A-4数据.txt 30,1980 461.1,751.9,750.1,985.4,479.5,465.5,535.4,829.6,298.1,635.2,536,830.1,230.1,513.1,684.8,352.7,711.5,462.3,596,515.7,527,616,594,352.5,582.4,724.6,846.6,692,322.6,454.1 1,1,1,1,1,5_ 计算结果文件为A-4.OUT *********************************************** **** 水文系列代表性分析计算书 **** *********************************************** (一）频率计算结果： 年份 值X 排队值X(%) 频率P(%) 1980 461.10 985.40 3.20 1979 751.90

## 输出

中文计算书（.OUT 格式），含输入数据回显、计算过程、结果；部分程序附图形（.BMP）。

## 使用方式

- 直接向 AI 描述工程参数，AI 按上述输入定义组织数据并计算。
- 或提供与原版兼容的 `.INT` 数据文件，AI 解析后计算。
- 计算结果可输出为 Markdown 计算书 / JSON / Word 文档。
