# 常用断面渠道水力学计算程序（D-6）

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序算法、公式与数据组织，用于现代环境调用与计算。
> 原程序作者：杨志河（水电部天津勘测设计院）

## 功能

1. **过水能力校核**（已知 B、H → 求 Q、V、Bo）
2. **求底宽 B**（已知 H、Q、M、N、I → 求 B）
3. **求均匀流水深 H**（已知 B、Q、M、N、I → 求 H）
4. **求底坡 I**（已知 B、H、Q、M、N → 求 I）
5. **水力最优断面**（已知 Q、M、N、I → 求 Bm、Hm）

适用于梯形（含三角形 B=0、矩形 M1=M2=0）及复式断面渠道水力计算。

## 算法原理

均匀流公式（谢才公式）：

```
断面面积  W = B·H + (M1+M2)·H²/2
湿周      X = B + H·(√(1+M1²)+√(1+M2²))
水力半径  R = W/X
谢才系数  C = (1/N)·R^Y
  巴甫洛夫斯基：Y = 2.5√N − 0.13 − 0.75√R(√N−0.10)（Y=0 默认）
  曼宁：Y = 1/6
流量      Q = W·C·√(R·I)
流速      V = C·√(R·I)
水面宽度  Bo = B + (M1+M2)·H
水力最优宽深比 Pm = 2·(√(1+M²)−M)
```

## 规范依据

传统水力学均匀流计算方法，不涉及规范替代问题。

## 输入数据（数据文件顺序）

```
断面类型(1=梯形,2=复式), 功能号(1求底宽/2求流量/3求水深/4求底坡/5最优断面),
B, H/Q, Q, M1, M2, N, Y, I
```

详见原程序说明书 D-6Intro.txt。

## 原版算例（D-61-1）

例1：梯形断面，边坡系数 M=1.5，糙率 N=0.025，底宽 B=7m，底坡 I=0.0003，
设计流量 Q=9.68 m³/s，**求设计渠高（均匀流水深）**。

## 输出（与原著一致）

- 均匀流水深 **H = 1.4403 m**
- 过水断面流量 **Q = 9.6799 m³/s**（校核）
- 断面平均流速 **V = 0.7337 m/s**
- 水面宽度 **Bo = 11.3209 m**
