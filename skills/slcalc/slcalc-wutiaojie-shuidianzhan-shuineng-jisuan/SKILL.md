# C-11 无调节水电站水能计算程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：黄 璜(新疆水利水电勘测设计院)

## 功能

本程序适用于无调节水电站的水能计算，可根据不同河流的来水情况，依计算者要求的精度得出如下结果： 流量~保证率关系曲线数据。 出力~保证率及发电持续时间关系曲线数据。 出力~年发电量关系曲线数据。 电站保证出力和设计流量。 可边疆输入若干个不同的装机容量从而计算出每一方案对应的年发电量、流量及发电持续时间。 计算原理及方法 计算原理主要参考成勘院主编《水能设计》第一章第五节中所述。将全部径流系列的日平均流量资料分成若干个流量阶梯进行统计计算，并据此进行能量计算。流量阶梯划分的密度可根据计算者的要求方便地划定。 程序特点 程序特点表现在对径流系列的统计计算中，程序先将全部径流系列分为五个大段，每个大段又分为若干个流量阶梯，计算者可根据径流系列的具体情况如：最大最小日流量值，不同流量值对整个径流系列的分布情况等等来确定每个大段的上下流量边界值及每段中划分的流量阶梯个数。这样可在流量出现较多的范围内使流量阶梯的划分相对较密，反之则相对较疏。基本资料一次输入后便可边疆计算得出各结果。对不同装机容量时的方案比较则可采用人机对话形式，每输入一装机容量便可得到相应的年发电量、设计流量和发电持续时间。程

## 输入数据（数据文件顺序）

P%SJ：电站设计保证率。 HSJ：电站设计净水头。 A：发电设备综合效率。 F：考虑发电流量损失后，水的利用系数(可根据计算阶段和精度的不同取<=1.0的值)。 Sjall：径流系列日平均流量总个数。 Sjmin,max：径流系列中最小和最大流量值(可取<=最小值和>=最大值的整数)。 Di：径流系列划分的五大段中第i段的上限流量值(I=1,2,3,4)。 Ii:所有Ii中的最大值。 例如：设某一电站具有若干年径流系列的日平均流量值2000个。其中最小值1.23m3/s。最大值823.5 m3/s。且大多数流量值分布在1.23~500 m3/s之间，故 对Sjall=提示可输入2000 对Sjmin,max=提示可输入1和825(取整) 第一大段上限定为50 m3/s，拟分为25个流量阶梯(D1=50，I1=25) 第二大段上限定为150 m3/s，拟分为20个流量阶梯(D2=150，I2=20) ……………………………………………………………………………… 第五段上限值机器自动以825代替，即D5缺省，仅需输入I5。可假设I5=5。由于所有段中最多划分了25个流量阶梯(I1=25)

## 输出

## 使用方式

- 直接向 AI 描述工程参数，AI 按上述输入定义组织数据并计算。
- 或提供与原版兼容的 `.INT` 数据文件，AI 解析后计算。
- 计算结果可输出为 Markdown 计算书 / JSON / Word 文档。
