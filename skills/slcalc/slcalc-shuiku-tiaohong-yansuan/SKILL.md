# C-2 Ｃ－２ 水库调洪演算的数值解程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：张校正（新疆水利厅 ）

## 功能

已知水库的水位--水面面积关系，洪水量过程线，对于每一种调洪方案（包括泄流条件、调洪方式、泄水建筑物参数）由调洪起始水位依次计算，直至洪水过程结束，计算机输出各时段末之水位、泄洪洞流量、溢洪道流量、水库出库总流量等。并用彩色曲线绘制洪水过程线、泄洪过程线和水库水位变化线。
