# A-12 下渗曲线产流计算程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：谢熙曦（水电部天津勘测设计院）

## 功能

本程序是根据毛雨量用霍顿下渗曲线和菲利下渗曲线计算净雨量。首先输入下渗曲线参数，计算下渗率F和土壤含水量S关系曲线然后输入雨量资料，计算各时段雨强H，初始土壤含水量Pa,通过读F～S曲线，得到下渗强度F。F与H比较后计算出本时段产流量及下一时段初的土壤含水量。这样逐时段演算下去，可计算出一个单元面积的产流过程和产流量。然后再计算第二个单元面积……。各个单元面积的计算结果按面积加权平均后得到全流域的产流过程和产流量。计算机输出各单元面积上的产流过程和产流总量以及全流域的产流过程和产流总量，并可输出F～S曲线点据。

## 原版算例

某流域有四个站的观测资料（三站版算例见说明书 Intro），要求用霍顿曲线计算流域的产流过程及产流量。
霍顿下渗曲线参数：C=1, FC=0.4, Fo=2.55, K=0.0817, D=2。
其他已知：TB=14.43, TS=14.55, DT=2, A=4。数据文件为 A-12数据.txt。

### 算例数据文件（A-12数据.txt）

```
1,.4,2.55,.0817,2
14.43,14.55,2,4
20.1,.4,14.49,1,14.51,1.6,14.53,4,14.55,6
14.7,.3,14.45,0,14.5,14.5,14.55,0
17.6,.3,14.45,0,14.51,5.3,14.55,7.6
20,.3,14.43,1,14.55,6
```

计算结果文件为 A-12-1.OUT（四站版），全流域产流量 SUMR=4.98 毫米。
A=3（说明书 Intro 三站版，数据 A-12G.INT）SUM 基准为 3.26（旧/裁剪版差异，见内核说明）。

## 计算要点

- 时间编码：TB/TS/T2 为"时.分"（14.43=14:43、14.5=14:50）。
- 产流时段：由 TB~TS 均分，间隔 DT（本算例 2min），共 B=6 时段；
  观测雨段内雨强均匀，但只取"完整 2min 产流格"的雨量参与演算，
  观测段端部不完整格被丢弃。
- 超渗产流：初始土壤含水量 S=Pa；每格段首 S 读 F~S 曲线（线性内插）得
  下渗强度 F，若雨强 H>F 则产流 R=H−F 且 S 增 F·Δt，否则全吸（S 增 H）。
- 权重：各单元产流 × 面积权重 E 后相加得全流域各时段产流与总量 SUMR。
