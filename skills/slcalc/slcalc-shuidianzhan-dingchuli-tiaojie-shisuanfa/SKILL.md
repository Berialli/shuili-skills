# C-6 水电站定出力调节计算(试算法)程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：唐文华(水电部天津勘测设计院)

## 功能

## Python 内核（slcalc C-6）

现代 Python 复刻见 `slcalc/programs/c06.py`（PROGRAM_ID="C-6"，注册于
`slcalc/programs/registry.py`），验证脚本 `slcalc/c6_verify.py` 与权威
C-6.OUT 对拍。权威对拍中裁定出的三个关键实现细节：

1. **SA=3 三点插值 =「最近端点侧三点 Lagrange 二次插值」**：x 落在段
   [VV[s],VV[s+1]] 内时，若距左端点更近取三点 (s−1,s,s+1)、若距右端点
   更近取三点 (s,s+1,s+2)，边界退化为可用三点，界外取端点。固定"右三点
   (s,s+1,s+2)"只能命中部分行。
2. **VB 以连续真实时段末库容滚动传递**（非显示舍入值），自 VG=1975 起调；
   水位 H=插值(时段末库容)、水头 DH=插值(0.5(VB+V))−18.45、出力
   N=8.3·QO·DH，QO/V/H/DH/N 五列同源于一条连续状态链。
3. **电量列恒显示 0**：原著对 E=N·730/1e8≈0.62 亿度作 FIX/int 截断（非
   舍入）。

c06.py 提供两种模式：`trial`（默认，正向试算：两级容差收敛至 NC=NT
物理精确根；与权威 OUT 的差 = 原著粗算轮 EP=0.1万kW 早停偏移，约
0.8~3.1 m³/s，见验证第④段误差表）；`fit`（核算/复现模式，给定
data/c6_qoreal.json 中由权威 OUT 唯一反演 ±0.002 的 QOreal 序列，逐
位复现 OUT 主表 5 列，35/35 全绿）。
