# A-13 随机水文AR(P)模型分析程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：孙建峰(水电部天津勘测设计院)

## 功能

水文随机系列生成(即人造系列)。

## 算法原理

详见原程序说明书。

## 规范依据

传统计算方法，不涉及规范替代问题（见《程序集适用于新规范的说明》）。

## 输入数据（数据文件顺序）

为： N，NM，M，Q(1)～Q(N)。 (二) 注释 ① 根据正态概率格纸法，如果系列为正态分布，经验频率点在格纸上密集在一条直线附近，否则为偏态分布。 又根据偏态检验法，对于正态分布系列来说，CS=0，如果实测系列的CS不异于零，可以认为该系列为正态分布，否则为偏态分布，当系列为正态分布时让ZP=0，否则ZP=1。 ② 如果原始系列的自相关系数R1，R2都很小，接近于0，曲线图无规则地绕0线波动见图1，即为独立系列，再结合r2=0.05表比较结果和安德生检验结果(如果点子“*”落在上下界内表示可用此模型)可选定AR(0)模型。如果自相关图呈现出指数衰减的形式或正负值相间变化，如图，结合安德生检验和r2=0.05比较结果可选定AR(1)或AR(2)模型。 AR(2)模型的情况与AR(1)大致相似，从图2可以看出AR(2)的相关线比A

## 原版算例

原版算例见说明书。算例数据文件为 **A-13数据.txt**（N=24 年径流系列，cc 取内核反推锁定值 2.3116），运行 `python calc.py A-13数据.txt` 即得随机水文 AR(P) 模型分析计算书文本。





## 输出

中文计算书（.OUT 格式），含输入数据回显、计算过程、结果；部分程序附图形（.BMP）。

## 使用方式

- 直接向 AI 描述工程参数，AI 按上述输入定义组织数据并计算。
- 或提供与原版兼容的 `.INT` 数据文件，AI 解析后计算。
- 计算结果可输出为 Markdown 计算书 / JSON / Word 文档。
