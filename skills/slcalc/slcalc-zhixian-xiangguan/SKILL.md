# 直线相关计算程序（A-1）

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序算法、公式与数据组织，用于现代环境调用与计算。
> 原程序作者：陈丽棠（水电部天津勘测设计院）

## 功能

1. 计算 Xi、Yi 两系列直线相关回归方程系数 **a、b**（最小二乘拟合）
2. 计算相关系数 **r**、相关系数标准差 **σr**、机误 **Er**（|r|>|4Er| 判为相关密切）
3. 计算两系列标准差 **σx、σy** 与均值 **X̄、Ȳ**
4. 已知 X 值插补 Y 值
5. 自动转换自变量与倚变量（以 X 倚 Y 或 Y 倚 X）重算上述全部参数

## 算法原理

Xi、Yi 为两系列对应观测值，若点据分布在直线附近则认为 X、Y 具有直线相关关系，
按**最小二乘原理**配合回归直线：

```
Y = a + b·X
b = Σ(Xi−X̄)(Yi−Ȳ) / Σ(Xi−X̄)²
a = Ȳ − b·X̄
r = Σ(Xi−X̄)(Yi−Ȳ) / √[Σ(Xi−X̄)²·Σ(Yi−Ȳ)²]
σr = (1−r²)/√n，Er = 0.6745·σr
```

当 |r| > |4Er| 时，说明两系列相关关系密切，可用回归方程进行插补延长。

## 规范依据

传统水文统计方法（最小二乘回归），不涉及规范替代问题。

## 输入数据（数据文件顺序）

```
系列项数 n
Xi 系列值（逗号分隔）
Yi 系列值（逗号分隔）
```

## 原版算例

拉萨、唐加两测站 17 年 9 月对应径流系列（1963-1983），计算回归方程、
相关系数、标准差、机误及系列均值，并转换自变量/倚变量重算。

- 回归直线方程 **Y = a + b·X**（a=77.697, b=0.682）
- 相关系数 **r=0.990**、标准差 σr=0.005、机误 Er=0.003（相关密切 ✓）
- 两系列标准差 σx=205.400、σy=141.391、均值
