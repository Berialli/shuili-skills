# A-14 A－14 马斯京根模型最优参数估计程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：叶泽纲（湖南省水文总站）

## 功能

已知一场洪水的实测入流 I(1..N)、出流 Q(1..N) 与计算时段 T(h)，用"槽蓄量排队 + 循环差统计"法直接估计马斯京根模型参数 X、K，并按所得参数演算出流过程。

> 方法溯源：前言所引"[1]新方法" = 杨荣富《马斯京根模型最优参数估计探讨》，《水文》1988,8(4):18-21（成都科技大学）。本程序为叶泽纲对该方法的 BASIC 实现。

## 算法原理

```
1. 河段槽蓄量 W（梯形累计，W(1)=0 起点可假定）：
     W(i) = W(i−1) + T·[(I(i−1)+I(i))/2 − (Q(i−1)+Q(i))/2]     [m³/s·h]
2. W 从小到大排队，I、Q 相应调整
3. 参数 X（三时刻循环差统计，对排序后序列 k=1..N−2）：
     V(k) = (Q_k−I_k)(W_{k+1}−W_{k+2}) + (Q_{k+1}−I_{k+1})(W_{k+2}−W_k)
            + (Q_{k+2}−I_{k+2})(W_k−W_{k+1})
     Y(k) = Q_k(W_{k+1}−W_{k+2}) + Q_{k+1}(W_{k+2}−W_k)
            + Q_{k+2}(W_k−W_{k+1})
     X = ΣV(k)Y(k) / ΣV(k)²     （输出取 3 位小数）
4. 示蓄流量：φ(i) = X·I(i) + (1−X)·Q(i)
5. 传播时间 K（W 对 φ 的带截距回归斜率）：
     K = [NΣφW − Σφ·ΣW] / [NΣφ² − (Σφ)²]     （输出取 2 位小数）
6. 演算：den = 2K(1−X)+T；C0=(T−2KX)/den、C1=(T+2KX)/den、C2=(2K(1−X)−T)/den
     O(1)=Q(1)、O(2)=Q(2)（前两点取实测出流）
     O(i) = C0·I(i) + C1·I(i−1) + C2·O(i−1)，i=3..N；打印取整
```

## 规范依据

传统计算方法，不涉及规范替代问题（见《程序集适用于新规范的说明》）。

## 输入数据（数据文件顺序）

数据文件：`N, T, I(1),Q(1), I(2),Q(2), …, I(N),Q(N)`——首行 N（点数）、T（小时），其后 **N 对 I/Q 交替**排列，逗号分隔。

原版算例 A-14数据.txt（14 点，T=6h）：
```
14,6,56,70,66,66,250,102,550,185,595,265,420,335,295,370,210
368,147,310,100,245,74,200,60,165,51,132,46,100
```

## 原版算例

A-14-1（A-14数据.txt）→ A-14.OUT：
```
X= .101     K= 18.21
实测入流值    出  流  值  演算出流值
 56            70            70
 66            66            66
 250           102           77
 550           185           149
 595           265           276
 420           335           364
 295           370           374
 210           368           344
 147           310           299
 100           245           249
 74            200           201
 60            165           161
 51            132           129
 46            100           105
```
X=0.101（内部 0.1012373424 舍入 3 位）、K=18.21（内部 18.2120 舍入 2 位）、演算 14 点逐位一致。

## 输出

中文计算书（.OUT 格式），含基本数据、参数估计（X/K）、演算结果（实测入流/出流/演算出流三列）、演算系数 C0/C1/C2。

## 使用方式

- 直接向 AI 描述工程参数，AI 按上述输入定义组织数据并计算。
- 或提供与原版兼容的 `.INT` 数据文件，AI 解析后计算（注意 I/Q 交替排列）。
- 计算结果可输出为 Markdown 计算书 / JSON / Word 文档。
