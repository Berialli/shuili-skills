# A-15 由直方图所限定的曲线拟合程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。
> 原程序作者：潘东海、朱凤娟（水利部天津勘测设计研究院）
> 算法论文：潘东海、刘世芬《由直方图限定的曲线拟合》，中国民航学院学报 1992 年第 4 期

## 功能

已知一个直方图（N 个分段常值的矩形：分段点 X(1..N+1)、各段柱高 y(1..N)）与首末点
标高 Y0、YM 及其导数 Y1、Y2，拟合一条**由直方图限定的曲线**：每个子区间内为二次曲线，
与 X 轴围成面积恰等于该区间矩形面积；各段在节点处 C1 连续；端导条件以最小二乘（权值
α、β）近似满足。输出各段 10 等分的采样点与曲线面积。

## 算法原理

```
直方图：N 段 [X_{j-1}, X_j]，柱高 y_j（j=1..N），H_j = X_j − X_{j-1}
节点标高 Y_0..Y_N（Y_0、Y_N 已知，内部 Y_1..Y_{N-1} 待求）

1. 段内二次曲线（归一化 t=(X−X_{j-1})/H_j）：
     S_j(X) = Y_{j-1}(1−t) + Y_j·t + C_j·t(1−t)
2. 面积守恒 ∫S_j dX = Q_j = y_j·H_j 解出二次项：
     C_j = 6Q_j/H_j − 3Y_{j-1} − 3Y_j = 6y_j − 3Y_{j-1} − 3Y_j
   （即段面积 = (Y_{j-1}+Y_j)H_j/2 + C_j·H_j/6 = y_j·H_j 恒成立）
3. 段间 C1 衔接 L_j（j=1..N−1，节点 X_j 处左导=右导）：
     (Y_j−Y_{j-1}−C_j)/H_j = (Y_{j+1}−Y_j+C_{j+1})/H_{j+1}
4. 端导条件 M_0、M_N：段1 左导=Y1（=Y'0）、段N 右导=Y2（=Y'N）
5. 超定 N+1 方程 / N−1 未知 → 加权最小二乘：
     min 4α(M_0² + M_N²) + β·Σ_j L_j²        ← 黑盒反推的等效目标
   α=ALF、β=BT 由键盘输入（α+β=1）。α=0 退化为纯 C1 方程组（N−1×N−1 恰定）。
6. 采样：X_0..X_N 每段 10 等分共 10N+1 点，标高输出 2 位小数；
   曲线面积 = 输出采样点逐点梯形积分。
```

> ⚠️ **权重修正说明（黑盒反推 2026-09-03，重要）**：说明书给出的目标为
> α(M_0²+M_N²)+βΣL_j²，但以例 2（ALF=0.3、BT=0.7）权威 OUT 反推，实际求解等效为
> **4α:β**（数值反推 r*=1.714283 ≈ 12/7 = 4×0.3/0.7 精确吻合）。若按输入 α:β 直解，
> 末节点 Y9=625.94 vs 权威 641.06（差 15.1）必错。可能原因：L_j 实际定义为 C1 差之半
> （半差平滑）使 β 项平方后等效缩为 β/4。α=0 时不受影响（例 1 仍纯 C1，101/101 命中），
> 两例自洽。

## 规范依据

传统计算方法，不涉及规范替代问题（见《程序集适用于新规范的说明》）。

## 输入数据（数据文件顺序）

```
第 1 行  N                    时段个数
第 2 行  X(1..N+1)            各分段点水平坐标（严格递增）
第 3 行  y(1..N)              各段直方块高（垂直坐标）
第 4 行  Y0, YM, Y1, Y2       初值标高、终值标高、初值处导数、终值处导数
第 5 行  KDX, KDY, YMIN, ALF, BT  水平刻度、垂直刻度、垂直原点、权 α、权 β
```

原版算例 A-15-1数据.txt：
```
10
2,4,5,7.5,10,12,14.5,17,18,20,22
2,4,6,5,3,2,3,4,6,5
1.1,3.4,1,-1
2,1,0,0,1
```
（例 2 A-15-2数据.txt 各值放大 100× 或 20×：X 起点 20、Y 量级数百，ALF=0.3、BT=0.7。）

## 原版算例

**例 1（A-15-1数据.txt，ALF=0、BT=1 纯 C1）→ A-15-1.OUT：**
- 内部节点（全精度）(3.20128, 4.84615, 6.07376, 3.85881, 2.24928, 2.30472,
  3.53185, 4.78892, 6.20277)，显示 2 位 (3.20, 4.85, 6.07, 3.86, 2.25, 2.30,
  3.53, 4.79, 6.20)
- 101 采样点逐点 2 位小数与 OUT **101/101 完全一致**
- 直方图面积 80.000、曲线面积 79.976（显示采样点梯形积分）

**例 2（A-15-2数据.txt，ALF=0.3、BT=0.7 加权）→ 权威 101 点：**
- 9 内部节点显示值 (323.45, 482.25, 608.59, 385.31, 225.56, 228.93, 356.91,
  471.78, 641.06) 全部命中
- 101 采样点 **100/101** 逐位一致（仅 X=90 全精度 479.015 处于 2 位舍入边界差 0.01）
- 曲线面积 79986.188 ≈ 权威 79986.148（相对差 5e-7）

## 输出

中文计算书（.OUT 格式）：基本数据（N、X、y、Y0/YM/Y1/Y2、权值）、曲线采样点
（每段 10 等分，双列 I-X-Y，2 位小数）、直方图面积与曲线面积。

## 使用方式

- 直接向 AI 描述工程参数（分段点、柱高、首末标高/导数、权值），AI 按上述输入定义组织数据并计算。
- 或提供与原版兼容的 `.INT` 数据文件，AI 解析后计算。
- 计算结果可输出为 Markdown 计算书 / JSON / Word 文档。
