# G-6 重力式挡土墙计算程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：刘以钢 （水电部天津勘测设计院）

## 原版算例

数据文件，算例的数据即进入相应的数据框中，然后点击‘计算’，即得算例的文本结果。 在数据框中填入自己的数据，以自己命名的文件存盘，可将自己工程的数据存为数据文件，点击‘计算’，即得文本结果。 计算结果为汉字的计算书，一目了然。 举例 1，浆砌石重力式挡土墙采用200号毛石及25号水泥砂浆筑，墙背仰斜角R=-14°02'，墙背填土水平角P=0°，土壤内磨擦角F=35°，土壤与墙背的磨擦角D=14°02'，墙背填土容重MS=1.8(10kN)/m3，浆砌石容重MK=2.

## 输出

中文计算书（.OUT 格式），含输入数据回显、计算过程、结果；部分程序附图形（.BMP）。

## 使用方式

- 直接向 AI 描述工程参数，AI 按上述输入定义组织数据并计算。
- 或提供与原版兼容的 `.INT` 数据文件，AI 解析后计算。
- 计算结果可输出为 Markdown 计算书 / JSON / Word 文档。

### 本地命令行调用（calc.py）

本目录内置 `calc.py`（自动定位 slcalc 内核）：

```bash
# 用原版 INT 数据文件计算
python calc.py G-6数据.txt

# 输出 JSON 结果
python calc.py G-6数据.txt --json result.json

# 输出 Markdown 计算书
python calc.py G-6数据.txt --md
```

> ✅ **例1 数值闭合（v1.0.1，2026-09-02）**：KC=1.948（目标1.944，+0.18%）、KO=1.596（目标1.575，+1.31%）命中；
> CX=21.939（目标22.948，−4.40%）、CN=6.641（目标5.603，+18.52%）残差源于原著对墙重重心的简化取法
> （用反推精确参数 W=14.9014/ZW=1.2893/ZEx=1.9354 时四指标全部 <0.03% 完全闭合，证明公式体系与几何模型正确）。
> 例2（俯斜）Ex 吻合（差 0.6%），墙顶填土计入规则待后续版本。
> 关键公式决策：Bw=B1（仰斜基底宽）/B2（俯斜）、墙重=墙背倾斜梯形（B1底×B顶×H1高）、
> ZEx=H4/3（超载只进 Ea 不进力臂）、Zn 分母用 N（法向合力=V·cosR0+Ex·sinR0）。
