# A-5X 同频率缩放设计洪水过程线程序

> **算法与数据来源：《水利水电工程设计计算程序集》公之于众版（乌鲁木齐正海水利科技有限公司）**
> 本技能忠实复刻原程序的算法、公式与数据组织，用于现代环境下的调用与计算。原程序作者：（原程序集编者）

## 功能

在已知典型洪水过程线、设计洪峰流量及各种历时设计洪量时，计算、打印并绘制典型设计洪水过程线。 本程序采用放大倍比K值函数新方法，具有计算速度快、能精确控制各时段设计洪量、保持设计过程基本不变形，并自行精确计算典型洪水各种时段最大洪量等特点。同时对典型过程时间坐标可任意摘录，缩放后的设计洪水过程时间坐标和典型过程相同，从面能很好地控制设计洪水过程线的形状，并能按要求输出等时距的设计洪水过程。

## 原版算例

算例数据文件为 **A-5X数据.txt**（典型洪水过程线 53 时段摘录 + 24/72/120h三控制时段设计洪量），运行 `python calc.py A-5X数据.txt` 即得三表一图的计算书文本。

数据文件，算例的数据即进入相应的数据框中，然后点击‘计算’，即得算例的文本结果和图形结果。 在数据框中填入自己的数据，以自己命名的文件存盘，可将自己工程的数据存为数据文件，点击‘计算’，即得文本结果和图形结果。 计算结果为汉字的计算书，一目了然。图形文件可插入计算书中。 程序共输出三表一图： 表1：打印N个控制时段的时段长和相应的典型洪量、设计洪量、缩放后的计算洪量及相对误差。打印典型及设计洪峰。 表2：打印典型和缩放后的洪水过程及相应的序号（控制时段的等流量点已插入）。



## 输出

中文计算书（.OUT 格式），含输入数据回显、计算过程、结果；部分程序附图形（.BMP）。

## 使用方式

- 直接向 AI 描述工程参数，AI 按上述输入定义组织数据并计算。
- 或提供与原版兼容的 `.INT` 数据文件，AI 解析后计算。
- 计算结果可输出为 Markdown 计算书 / JSON / Word 文档。
