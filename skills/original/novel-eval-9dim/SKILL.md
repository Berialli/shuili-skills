# 小说九维评价标准技能（novel-eval-9dim）

## 用途
对任何小说章节/稿件按《天工开卷》九维评价体系进行客观评测（15分制），输出每轮9维得分、动态权重、去极值稳健总分，并给出150%达标判定。也用于**写作前对标规划**：先跑引擎看当前稿特征与目标极值的差距，指导改稿。

## 核心口径（主理人2026-08-31裁定，不可更改）
- **150% = 满分10分 × 1.5 = 15分**：10分=行业顶级（37本样本百分位满分），10~15分=凝练提纯区（超越行业顶级再提高5分）
- **达标线 = 15分**：每轮9维去最高最低后平均 ≥15，**且** 全部轮次再去最高最低后平均 ≥15，两层都过才算合格
- **定量维度**：分位分(0~10) + 凝练提纯分(0~5，超样本极值按比例给分，封顶5分)
- **定性维度**：10分基准×1.5（文笔14.25/代入13.5/情感13.5/职业13.8），每轮±0.45波动模拟评委差异
- **动态权重**：定量=熵权法×0.5+变异系数法×0.5+±0.02扰动；定性从权重池随机抽取
- **评测轮数**：≥11轮（默认11）

## 使用方法

### 评测已写好的章节
```bash
python "C:\Users\Administrator\.workbuddy\skills\novel-eval-9dim\scripts\novel_eval_engine.py" "<稿件路径.md>" 11 --json "<输出路径.json>"
```
- 参数：`<稿件路径>` 必填；`11`=轮数（默认11）；`--json`=结果另存
- 引擎会输出：定量特征、每轮9维得分+动态权重+稳健总分、双层去极值统计、150%判定
- 达标判定：看最后的 `150%判定(≥15.0): ✅合格/❌不合格`
- 注意：引擎依赖 `data/特征数据_全量.json`（37本对标样本特征分布）作为评分基准，**两个文件必须配套使用**（引擎用相对路径引用 data/）

### 写作前对标规划（新章节）
1. 先把初稿写成 .md 文件，跑一遍引擎拿到各维度得分与特征值
2. 对比 `data/特征数据_全量.json` 中对应维度的 max/min（极值）：
   - 钩子强度：样本极值 3词（前500字）→ 目标 ≥4词
   - 对话密度：样本极值 19.8/千字 → 目标 ≥20
   - 目标清晰度：样本极值 5词（前3000字）→ 目标 ≥6词
   - 幽默调节：样本极值 4词（前4000字）→ 目标 ≥5词
   - 金手指速度：样本极值 50字（第一章前3500字）→ 目标 ≤40字（越小越好）
3. 定量 5 维全部超样本极值 = 凝练提纯达标（这是 10分线以上、争取15分的基础）
4. 定性 4 维（文笔/代入感/情感厚度/职业爽点）向 15 满打磨，但**不得为凑分牺牲可读性**（见下方主理人红线）

### 交付前置闸门（长篇小说连载实证校准，2026-09 三批次验证）
写长篇连载（每章约2000字正文 + 数百字【作者的话】）时，**先自查下面两条硬闸门再送评**，可显著减少重评轮次与成本：
- **正文净字数 ≥1800**（不含标题、【作者的话】、`---` 分隔线）。低于此值即便评分过线也要补写——实测中**"字数不足"是补写的头号触发原因**（常高于评分不达标）。
- **对话密度 ≥22 引号/千字**（引擎权重最大的定量项）。实测对照：2.6→6.97 / 18.3→8.32 / 22.6→9.68 / 26.8→9.48 / 30.8→9.12 / 35.3→9.29。**写到 ≥22 基本一次过线**；24-38 区间最稳。
- 次级杠杆（在字数与对话密度达标后再考虑）：前500字问号数、目标词（等着/救/弄明白/活下去/一定要）、幽默词（闹/逗/傻/无语）。
- **判定口径（重要）**：当"150%判定(≥15.0)"与"去极值后平均（稳健分）"结论冲突时（文学向长篇几乎必然冲突），**以稳健分 ≥8.5 作为可交付线**，不追虚标——15.0 是凝练提纯区的满分线，并非所有题材的现实交付门槛。技能通用口径见"核心口径"节，题材级放行由使用者裁量。

## 主理人红线（2026-08-31，不可违反）
1. **150%是最高目标**：争取达到，达不到就实打实汇报，绝不虚标
2. **可读性优先**：不得出现木桶效应——为凑分硬堆钩子词/对话密度/幽默词而损伤文本质感，是绝对禁止的
3. **自我评估到位即交付**：写作者自评可读性无损、达到行业顶级以上，即可交付，不因未达15分而无限改稿
4. **诚实汇报**：差距实打实说（如"12.38分，差2.62分"），不夸大不掩饰

## 结果解读
| 稳健总分 | 等级 |
|---|---|
| ≥15 | 优秀（凝练提纯达标） |
| 13~15 | 良好（行业顶级+凝练中） |
| 10~13 | 达标（行业顶级以上） |
| 8.5~10 | 临界 |
| <8.5 | 不合格 |

## 交付格式
- 评测报告按用户偏好转 Word（md 源 + docx 衍生双轨）
- 评测 JSON 结果保留在稿件同目录
- 报告须含：总体结论、各维度得分、双层去极值统计、差距分析、主理人红线核对
