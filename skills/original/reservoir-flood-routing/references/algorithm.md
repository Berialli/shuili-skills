# 水库双辅助曲线调洪演算 — 算法原理与工程说明

## 1. 方法概述

本程序采用**双辅助曲线法（半图解法）**进行水库调洪演算，算法源自原 Excel VBA 调洪演算程序。

调洪演算的基本方程：

```
水量平衡方程：  (Q1 + Q2)/2 × dt = (q1 + q2)/2 × dt + ΔV
蓄泄方程：      q = f(V)  （由水位~库容 + 水位~泄流能力关系组合而成）
```

双辅助曲线法将两方程联立转化为**两条辅助曲线的图解法递推**，无需迭代求解，适合逐时段手算复核，也便于程序化。

## 2. 单位换算系数 0.36 的由来

| 物理量 | 单位 |
|---|---|
| 库容 V | 10^4 m³ |
| 流量 Q, q | m³/s |
| 时段长 dt | h |

换算：V/dt 需从 (10^4 m³ / h) 转为 (m³/s)：

```
1 10^4 m³ / 1 h = 10000 m³ / 3600 s = 2.7778 m³/s
即 V[m³/s] = V[10^4 m³] / (dt[h] × 0.36)
```

**系数 0.36 = 3600 / 10000**（秒/小时 ÷ 万方换算）。

## 3. 辅助曲线计算

输入：水位~下泄流量~总库容关系表（水位单调递增），计算时段 dt。

```
V0               = 第一个点的总库容（起调水位对应库容，视为溢洪道堰顶以上基准）
V_溢洪以上       = V总 - V0                    (10^4 m³)
V/dt             = V_溢洪以上 / (dt × 0.36)    (m³/s)
q/2              = 下泄流量 / 2                (m³/s)
辅助曲线1(减)    = V/dt - q/2                  (m³/s)
辅助曲线2(加)    = V/dt + q/2                  (m³/s)
```

## 4. 调洪演算（逐时段递推）

设第 i 时段来水 Qi、下泄 qi、水位 Gi：

```
步骤1  平均来水：Qp = (Qi + Qi-1) / 2
步骤2  加辅助值：(V/dt + q/2)i = Qp + (V/dt - q/2)i-1
步骤3  查加辅助曲线（线性内插）→ 得 qi 与 (V/dt - q/2)i
步骤4  由 qi 查水位~流量关系（线性内插）→ 得水位 Gi
```

初始条件：起调水位 = 辅助曲线第一点水位，初始下泄流量 = 0。

**注意**：第 0 时段为初始状态（来水 0 / 下泄 0 / 起调水位），从第 1 时段开始递推。

## 5. 特征值提取

```
最大下泄流量 q_max 及其发生时段
最高水位 H_max 及其发生时段
最大来水流量 inflow_max
最大调蓄库容 V_调蓄 = max(累计 Σ(Qp - q) × dt × 0.36)   (10^4 m³)
```

## 6. 数据格式约定

### 辅助曲线表（Excel A/B/C 列）
| A | B | C |
|---|---|---|
| 水位 (m) | 下泄流量 (m³/s) | 总库容 (10^4 m³) |

要求：水位**单调递增**；第一点为起调状态（溢洪道堰顶水位）。

### 洪水过程线表（Excel A/B/C 列）
| A | B | C |
|---|---|---|
| 时段序号 | 时段长 dt (h) | 来水流量 (m³/s) |

要求：第 0 行为初始状态（来水 = 0）；dt 可逐时段不同。

## 7. 适用范围与注意事项

1. **适用**：无闸门自由泄流（溢洪道）水库的调洪演算；闸门调度可近似为分级泄流曲线。
2. **限制**：辅助曲线数据必须覆盖演算可能达到的水位区间；超出曲线范围时程序取端点值外推（结果仅作参考）。
3. 当泄流能力随水位非线性显著时，需加密水位~流量数据点以保证内插精度。
4. 本方法为**半图解法**，与完全数值解法（如 4 阶 Runge-Kutta 求解圣维南简化方程）在 dt 较大时存在小幅差异；工程常规 dt = 1~2 h 精度足够。
5. 引用规范：调洪演算相关内容可参考 SL 252-2017《水利水电工程等级划分及洪水标准》、SL 44《水利水电工程设计洪水计算规范》（如涉及设计洪水复核）。
6. 结果精度：流量保留 2 位小数，水位保留 3 位小数（与原程序一致）。
